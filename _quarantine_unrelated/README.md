# KC Tree Pros Lead Site

Static HTML/CSS lead-generation website for tree services in Kansas City.

## Deploy on Netlify

1. Create a new Netlify site from this folder.
2. Keep publish directory as `.` (already set in `netlify.toml`).
3. Optional: update phone, email, business address, and domain references in the HTML files.

## Included Pages

- Home (`index.html`)
- Tree Removal Kansas City
- Emergency Tree Removal Kansas City
- Stump Grinding Kansas City
- Storm Damage Tree Removal Kansas City

## Lead Form

All pages include a Netlify form (`lead-form`) with fields:

- Name
- Phone
- Address
- Service Needed
