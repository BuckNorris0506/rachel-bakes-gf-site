# First-Fix Preview SOP

## Purpose
A First-Fix Preview is a small pre-outreach proof asset that shows a prospect:
- we identified the most important leak
- we know what to fix first
- we can visualize the improvement

It is not a full free website, a full redesign, a giant unpaid consulting deliverable, or a generic AI blast.

The goal is simple: raise reply rate with top prospects by showing the first fix clearly.

## What a First-Fix Preview Is
A First-Fix Preview is a selective sales asset built before outreach for a very small number of high-fit prospects.

Core rule:
- one leak only
- one fix only

Tone rule:
- Here is the first thing I would fix.
- Not: here is a full free strategy project.

## When To Use It
Use a First-Fix Preview only when all of the following are true:
- the prospect is in the top 1–2 names in a batch
- the business is a strong fit that we would actually want
- the site has an obvious trust or intake leak
- the leak is easy to show visually
- the contact data is credible enough to justify the extra effort

## When Not To Use It
Do not use a First-Fix Preview for:
- every lead in a batch
- low-fit prospects
- weak or suspicious contact data
- businesses where the main leak is unclear
- giant custom mockups
- anything that turns into unpaid custom labor

## Allowed Preview Formats
Use only these formats right now:
1. Annotated screenshot
2. One-section mockup

Optional later:
3. Loom walkthrough
4. Private preview page

Recommended current format:
- annotated screenshot
- plus optional one replacement section mockup if the leak is especially visual

## Time Limit
Target time:
- 10 to 20 minutes per preview

Hard cap:
- 20 minutes

If a preview is not clearly useful inside 20 minutes, stop and move the prospect back to normal outreach.

## Current Outbound Ladder
- Tier 1 = normal personalized outreach
- Tier 2 = First-Fix Preview for top prospects
- Tier 3 = reply-stage teardown or call

The preview is a selective sales weapon, not the whole business model.

## Step-by-Step Workflow
### 1. Choose the right prospect
Confirm the prospect is:
- high fit
- worth winning
- visually diagnosable
- reachable through a credible contact path

### 2. Define the leak in one sentence
Write the leak as one plain sentence.

Examples:
- The gallery proof is too weak near the estimate path.
- The phone number and request path are buried on mobile.
- The homepage does not build enough trust before asking for action.

If you cannot define the leak in one sentence, do not build the preview.

### 3. Define the first fix in one sentence
Write the first fix as one plain sentence.

Examples:
- Move proof and project photos above the first call-to-action.
- Replace the first section with a clearer service-and-trust block.
- Simplify the mobile quote path to one obvious next step.

If the first fix is broad or turns into multiple fixes, narrow it down.

### 4. Choose preview type
Default choice:
- annotated screenshot

Use a one-section mockup only if:
- the leak is easy to improve visually
- the replacement can be shown quickly
- it can still be finished inside the time cap

### 5. Create the preview
Build only enough to make the first fix obvious.

For an annotated screenshot:
- capture the current section
- mark the leak clearly
- add 1 to 3 short annotations maximum
- label the first fix

For a one-section mockup:
- mock only the section tied to the leak
- keep the scope tight
- do not build extra pages or full-site concepts

### 6. Send the outreach
Use the preview as support for outreach, not as the whole message.

The outreach should point to:
- the leak
- the first fix
- the fact that we already looked closely

Do not turn the email into a giant explanation.

### 7. Track outcome
Log the preview in the tracker immediately.
Track:
- what was made
- how long it took
- when outreach was sent
- whether a reply came in
- whether the preview helped move the conversation forward

## Quality Standard
A good First-Fix Preview should be:
- specific
- fast to understand
- visually clear
- narrow in scope
- useful in under 30 seconds of attention

A good preview should make the prospect think:
- they actually looked at my business
- they understand the leak
- they know where to start

## Outreach Usage Rule
Use First-Fix Previews selectively.
They are for top prospects only.

Do not build them by default.
Do not let them become a free fulfillment process.
Do not let them replace the normal outreach ladder.

## How To Track Results
Track each preview in the First-Fix Preview tracker.

Minimum rule:
- one row per preview
- update the same row as the prospect moves forward

Important fields to maintain:
- leak summary
- first fix summary
- preview type
- file path
- time spent
- outreach sent date
- reply received
- positive response
- meeting booked
- deal status

Review tracker results by batch to answer:
- which preview types get replies
- which leaks are easiest to convert with
- whether the time spent is justified

## Common Mistakes To Avoid
- making the preview too big
- solving multiple problems at once
- building a full free concept
- using it on low-fit leads
- making generic annotations that could apply to anyone
- spending more than 20 minutes
- skipping the tracker
- sending the preview without a clear ask
